Help Centre

Learn how to create projects, use the 3D CAD workspace, edit objects, save designs, import models and export your work.

Go to Dashboard View Projects

1. Getting Started

  1. Login to your Objex CAD account.
  2. Open the dashboard.
  3. Click + New Project.
  4. Enter project name and description.
  5. Open the project to start designing.

2. Project Management

The Projects page allows you to view all saved projects, open existing designs, rename projects, delete projects and import external model projects.

  • Open Project: loads the selected CAD workspace.
  • Rename Project: updates name and description.
  • Delete Project: removes a saved project.
  • Import Project: imports supported 3D model files.

3. CAD Workspace Tools

Add Shape Create cube, sphere, cylinder, cone, torus, pyramid or plane.
Select Object Click any object in the workspace to edit it.
Move Object Move selected object on X, Y and Z directions.
Rotate Object Rotate selected object using manual or button controls.
Resize Object Change scale and dimensions of the selected object.
Duplicate Object Create a copy of the selected object.
Delete Object Remove the selected object from the workspace.
Colour & Materials Apply colour, plastic, metal, glass, wood, neon or transparent material.
Grid & Axes Use grid and X/Y/Z axes for better alignment and direction.
Zoom, Pan & Orbit Control the camera view without changing the object.
Undo & Redo Reverse or restore recent workspace actions.
Reset Workspace Clear the workspace and return to a clean design area.

4. Save and Export

Use Save Design to store the current CAD workspace in the database. You can export your work as an image or 3D model file for presentation and submission.

  • Save regularly after editing objects.
  • Export image for screenshots and documentation.
  • Export model for 3D file sharing.

6. Troubleshooting

Object is not moving?

Select the object first, then open the Move Object tool.

Saved project is empty?

Make sure you click Save Design after adding or editing objects.

Import is not working?

Check that the selected file format is supported, such as GLB, GLTF or OBJ.

View is difficult to control?

Use Reset View, Zoom, Pan and Orbit controls to return to a comfortable camera position.
